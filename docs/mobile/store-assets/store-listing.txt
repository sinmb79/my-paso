- HTTP localhost는 같은 기기 안에서 처리되며 기기 밖 수집이 아님

[Short description]

[Full description]
Hello! My Paso! is a local-first journal that turns places into a private map and timeline. Start without an account; visits, photos, and reflections are stored in app-private storage by default.

Discover places
- Explore 100 real places in South Korea on a map and in a list
- Save places, create personal tags, search, and filter
- Review previous visits and notes from place details

Record memories
- Distinguish GPS-verified and manual visits
- Add a photo, note, rating, and reflection
- Browse a chronological journal and true visit anniversaries
- Export and restore a checksummed JSON backup

Write faster with optional local AI
- Draft journal text, classification, and keywords from the selected place name and note
- A vision model receives only a resized temporary photo copy with EXIF removed
- Nothing is sent before a transfer preview and explicit confirmation
- Output is an editable draft, never auto-saved, synchronized, or shared

Owner-controlled connection
- HTTP/HTTPS localhost on this device or an exact user-confirmed HTTPS private-LAN IPv4 endpoint is accepted
- HTTP private-LAN, public-internet, cloud, and developer-operated AI endpoints are blocked; HTTPS private-LAN is allowed after confirmation
- HTTPS private-LAN use is an off-device transfer, its operator can process the content, and platform TLS encrypts it in transit
- The developer does not operate an AI endpoint or receive, retain, or inspect requests
- HTTP localhost stays on-device and is not off-device collection
- Precise location, photo metadata, other records, and backups are excluded
- No model weights are bundled; the user supplies a compatible local runtime

There are no accounts, ads, behavioral tracking, or remote analytics. Location is used only for an explicit on-site check, with no background tracking. AI is optional and all manual journal features remain available without it.

Version 0.3.0 is a closed-test update for optional local AI and a refreshed visual and accessibility experience. Its 100 bundled places come from a 19 July 2026 Wikidata structured-data snapshot under CC0. Venue status and coordinates can change after the snapshot date.

Free, with no ads or subscriptions.
