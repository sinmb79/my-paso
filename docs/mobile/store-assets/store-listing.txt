Hello! My Paso!는 장소에서 보낸 순간을 지도와 타임라인으로 남기는 로컬 퍼스트 저널입니다. 계정을 만들지 않아도 바로 시작하고, 나의 방문과 사진, 감상은 개발자 서버가 아니라 내 기기에 머뭅니다.

장소를 발견하세요
- 지도와 목록에서 100개의 테스트 장소 탐색
- 장소 저장, 나만의 태그, 검색과 필터
- 장소 상세 화면에서 방문 이력과 메모 확인

기억을 솔직하게 기록하세요
- 현재 위치를 사용한 GPS 확인 방문
- 현장이 아닐 때 남길 수 있는 수동 기록
- GPS 확인과 수동 기록을 구분해 표시
- 방문 사진, 메모, 별점과 감상
- 시간순 저널과 실제 방문 기념일

나의 여정을 돌아보세요
- 방문과 기록으로 쌓이는 XP와 정확한 레벨 진행률
- 월간 회고와 방문 통계
- 탐험 성과를 보여 주는 업적

로컬 퍼스트
- 계정, 광고, 행동 추적, 원격 분석 없음
- 위치는 현장 확인을 직접 실행할 때만 사용
- 카메라는 방문 사진을 추가할 때만 사용
- 방문, 좌표, 사진, 태그와 리뷰는 앱 전용 저장소에 보관
- 체크섬이 포함된 JSON 전체 백업과 복원
- 외부 지도나 공공 API 키가 없어도 핵심 기능 동작

이번 0.2.0은 제품 경험과 로컬 데이터 영속성을 검증하는 비공개 테스트 버전입니다. 100개 장소는 기능 검증용 더미 데이터이며 공개 출시 전 출처와 라이선스가 확인된 실제 POI로 교체됩니다.

무료이며 광고와 구독이 없습니다.

[App name]
Hello! My Paso!

[Short description]
Keep visits, photos, and reflections privately on your device

[Full description]
Hello! My Paso! is a local-first journal that turns places into a private map and timeline of your memories. Start without an account. Your visits, photos, and reflections stay on your device rather than a developer server.

Discover places
- Explore 100 test places on a map and in a list
- Save places, create personal tags, search, and filter
- Open place details to review previous visits and notes

Record memories honestly
- Verify an on-site visit with your current location
- Add a manual visit when you are recording from elsewhere
- See a clear label for GPS-verified and manual entries
- Add a visit photo, note, rating, and reflection
- Browse a chronological journal and true visit anniversaries

Review your journey
- Earn XP with exact level progress
- See a monthly recap and visit statistics
- Unlock exploration achievements

Local first
- No account, ads, behavioral tracking, or remote analytics
- Location is used only when you explicitly verify an on-site visit
- Camera access is used only when you add a visit photo
- Visits, coordinates, photos, tags, and reviews stay in app-private storage
- Full JSON backup and restore with checksum validation
- Core features work without external map or public API keys

Version 0.2.0 is a closed-test build for validating the experience and on-device persistence. Its 100 places are dummy test data and will be replaced with licensed, verified POIs before the public production release.

Free, with no ads or subscriptions.
