Hello! My Paso! 0.3.0 비공개 테스트 업데이트입니다.

- 사진·메모로 기록, 장소 분류와 키워드 초안을 만드는 선택적 로컬 AI
- HTTP/HTTPS localhost 또는 직접 확인한 HTTPS 사설망 실행기만 허용하고 HTTP 사설망·공개·클라우드 엔드포인트 차단
- 전송 미리보기와 명시적 확인, 사진 EXIF 제거, 정확한 위치·다른 기록 제외
- AI 결과는 편집 가능한 초안이며 자동 저장·동기화·공유하지 않음
- 지도 장소 겹침 완화, 탐색 필터 간소화와 사실적인 ‘장소 분포도’ 안내
- 화면 질감, 명암, 키보드 포커스와 작은 화면 접근성 개선

AI는 선택 사항이고 모델은 앱에 포함되지 않습니다. HTTPS 사설망 사용은 기기 밖 전송이며 운영자가 내용을 처리할 수 있고 플랫폼 TLS로 암호화됩니다. HTTP localhost는 같은 기기 안에서 처리됩니다. 개발자는 AI 실행기를 운영하거나 요청을 수신·보관·열람하지 않습니다.
