Hello! My Paso! 0.2.0-alpha3 비공개 테스트 업데이트입니다.

- 기능 검증용 더미 100건을 Wikidata CC0 기반 대한민국 실제 장소 100건으로 교체
- 기존 알파의 더미 방문 기록은 보존하고 지도·탐색에서는 실제 장소만 표시
- 장소 저장, 나만의 태그, 검색·필터와 상세 화면
- GPS 확인 방문과 수동 방문을 구분하는 정직한 기록
- 방문 사진, 메모, 별점과 타임라인
- 월간 회고, 업적과 정확한 레벨 진행률
- 체크섬 기반 전체 백업·복원과 민감 데이터 로그 차단
- 지도·목록 성능 및 휴대전화·태블릿 화면 완성도 개선

위치와 카메라는 사용자가 해당 기능을 직접 실행할 때만 요청합니다. 계정, 광고, 추적, 원격 분석은 없습니다.
