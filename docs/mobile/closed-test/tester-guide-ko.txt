[Hello! My Paso! Android 비공개 테스트 초대]

Hello! My Paso! 0.3.0의 Google Play 비공개 테스트에 참여해 주셔서 감사합니다.

참여 조건
- Android 휴대전화 또는 태블릿
- 초대받은 Google 계정으로 Play Store 로그인
- 참여 후 14일 동안 테스트에서 탈퇴하지 않기
- 최소 3개의 테스트 미션 수행 후 짧은 피드백 남기기
- Android System WebView 또는 Chrome을 최신 버전으로 업데이트

참여 방법
1. 전달받은 Google Play 옵트인 링크를 엽니다.
2. 초대받은 Google 계정인지 확인합니다.
3. 테스터로 참여를 선택합니다.
4. Play Store 설치 링크에서 앱을 설치합니다.
5. 함께 전달된 테스트 미션을 수행합니다.

앱 안내
- 계정, 광고, 행동 추적, 원격 분석이 없습니다.
- 방문, 좌표, 사진, 태그, 감상과 XP는 기본적으로 앱 전용 저장소에 저장됩니다.
- 위치는 현재 위치 확인을 누를 때, 카메라는 사진 추가를 누를 때만 요청합니다.
- 백그라운드 위치 추적은 없습니다.
- 100개 장소는 2026-07-19 Wikidata CC0 스냅샷으로 앱에 번들된 대한민국 실제 장소입니다.
- 장소 운영 상태나 중심 좌표가 현장과 다르면 수동 방문으로 기록하고 피드백에 장소 이름을 적어 주세요.
- 내보낸 JSON에는 좌표와 사진이 포함될 수 있으므로 공개 공유하지 마세요.
- 로컬 AI는 선택 사항이며 설정하지 않아도 수동 기록 기능을 모두 사용할 수 있습니다. 모델 가중치는 앱에 포함되지 않습니다.
- 앱은 이 기기의 HTTP/HTTPS localhost 또는 직접 확인한 HTTPS 사설망 IPv4 실행기만 허용합니다. HTTP 사설망과 공개·클라우드·개발자 운영 엔드포인트는 차단합니다.
- AI는 전송 미리보기와 명시적 확인 뒤 선택한 장소 이름·메모, 그리고 비전 모델에서는 EXIF를 제거한 임시 사진 복사본만 보냅니다. 정확한 위치, 사진 메타데이터, 다른 기록과 백업은 보내지 않습니다.
- HTTPS 사설망 AI는 기기 밖 전송이며 엔드포인트 운영자가 내용을 처리할 수 있고 플랫폼 TLS로 암호화됩니다. HTTP localhost는 같은 기기 안에서 처리됩니다. 개발자는 AI 실행기를 운영하거나 요청을 수신·보관·열람하지 않습니다.
- AI 미션에서는 HTTP 사설망 거부와 HTTPS 사설망 소유 확인을 모두 검사합니다. 제공된 더미 사진·더미 메모와 유효한 인증서의 직접 통제 테스트 실행기만 사용하고 개인 자료는 쓰지 마세요.
- 수신 로그에서 전송 항목과 제외 항목을 확인하고, 테스트가 끝나면 실행기 로그와 더미 파일을 삭제해 주세요.
- AI 결과는 편집 가능한 초안이며 자동 저장·동기화·공유되지 않습니다. 실패나 타임아웃 뒤에도 입력과 기존 기록이 유지되어야 합니다.

문제가 생기면 아래 내용을 보내 주세요.
- 휴대전화 또는 태블릿 모델
- Android 버전
- Android System WebView 또는 Chrome 버전
- 어떤 화면에서 무엇을 했는지
- 기대한 결과와 실제 결과
- 가능하면 화면 캡처
- AI 미션이면 개인 내용이 없는 수신 로그의 필드 이름과 실패 후 입력 유지 여부(비밀 값·본문은 보내지 않기)
