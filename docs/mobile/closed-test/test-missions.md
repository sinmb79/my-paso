# 비공개 테스트 미션

테스터 한 명당 미션 1~3을 기본으로 수행하고, 일부 테스터는 미션 4~5까지 진행합니다. 위치와 카메라 권한은 관련 기능을 직접 실행할 때만 표시되어야 합니다.

## 미션 1: 탐색·저장·태그

1. 지도, 탐색, 저널, 프로필 탭을 한 번씩 엽니다.
2. 탐색에서 장소를 저장하고 나만의 태그를 추가합니다.
3. 검색·카테고리·저장됨 필터로 같은 장소를 찾습니다.
4. 상세 화면을 열어 이름, 지역, XP와 기록 영역을 확인합니다.

통과 기준: 네 탭과 장소 상세가 충돌 없이 열리고 저장·태그·필터 상태가 즉시 반영됩니다.

## 미션 2: GPS·수동 방문과 사진

1. 한 장소에서 방문 기록을 엽니다.
2. 가능하면 현재 위치 확인을 실행하고 위치 권한 흐름을 확인합니다.
3. 현장이 아니면 수동 기록을 선택합니다.
4. 메모와 사진을 추가하고 저장합니다.
5. 저널에서 GPS 확인 또는 수동 기록 라벨과 사진을 확인합니다.

통과 기준: 거짓 GPS 확인으로 표시되지 않고 선택한 확인 방식, 메모와 사진이 정확히 저장됩니다.

## 미션 3: 감상·프로필·업적

1. 방문한 장소에 별점과 감상을 저장합니다.
2. 프로필에서 방문, 사진, 리뷰, XP와 레벨 진행률을 확인합니다.
3. 월간 회고와 업적 상태를 확인합니다.
4. 저널에서 시간순 기록과 기념일 표시를 확인합니다.

통과 기준: 입력한 기록과 통계가 일관되게 반영되고 중복 XP가 생기지 않습니다.

## 미션 4: 강제 종료 영속성

1. 앱을 최근 앱 화면에서 완전히 종료합니다.
2. 앱을 다시 실행합니다.
3. 저장 장소, 태그, 방문, 사진, 리뷰와 XP를 확인합니다.
4. 가능하면 기기 재부팅 후 한 번 더 확인합니다.

통과 기준: 종료 또는 재부팅 후에도 모든 로컬 기록이 유지됩니다.

## 미션 5: 전체 백업과 복원

1. 프로필에서 JSON 백업을 내보냅니다.
2. Documents에 파일이 생성되거나 공유 시트가 열리는지 확인합니다.
3. 백업 파일을 안전한 위치에 보관합니다.
4. 테스트에 동의한 경우 앱 데이터를 초기화합니다.
5. 시스템 파일 선택기에서 같은 JSON을 선택해 복원합니다.
6. 저장 장소, 태그, 방문, 사진, 리뷰, XP가 모두 돌아왔는지 확인합니다.

통과 기준: 무결성 미리보기가 실제 건수와 일치하고, 유효한 백업만 전체 복원되며 실패 시 기존 데이터가 손상되지 않습니다.

주의: 내보낸 JSON은 좌표와 사진을 포함할 수 있고 별도로 암호화되지 않습니다. 공개 채널에 올리지 말고 테스트 뒤 삭제합니다.

## 심각도

- P0: 앱 실행 불가, 데이터 전체 손실, 반복 충돌, 복원으로 기존 데이터 손상
- P1: 핵심 미션 완료 불가, 기록이 재시작 후 사라짐, 권한 없이 민감 기능 실행
- P2: 일부 버튼·레이아웃·문구·성능 문제, 우회 가능
- P3: 개선 제안 또는 사소한 불편
