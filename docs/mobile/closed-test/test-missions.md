# 비공개 테스트 미션

테스터 한 명당 미션 1~3을 기본으로 수행하고, 일부 테스터는 미션 4~6까지 진행합니다. 위치와 카메라 권한은 관련 기능을 직접 실행할 때만 표시되어야 합니다. 미션 6은 개인 자료가 아닌 제공된 더미 사진·더미 메모와 수신 로그를 확인할 수 있는 테스트 엔드포인트로만 수행합니다.

## 미션 1: 탐색·저장·태그

1. 지도, 탐색, 저널, 프로필 탭을 한 번씩 엽니다.
2. 탐색에서 장소를 저장하고 나만의 태그를 추가합니다.
3. 검색·카테고리·저장됨 필터로 같은 장소를 찾습니다.
4. 상세 화면을 열어 이름, 지역, XP와 기록 영역을 확인합니다.

통과 기준: 네 탭과 장소 상세가 충돌 없이 열리고 저장·태그·필터 상태가 즉시 반영됩니다.

## 미션 2: GPS·수동 방문과 사진

1. 한 장소에서 방문 기록을 엽니다.
2. 가능하면 현재 위치 확인을 실행하고 위치 권한 흐름을 확인합니다.
3. 현장이 아니면 수동 기록을 선택합니다.
4. 메모와 사진을 추가하고 저장합니다.
5. 저널에서 GPS 확인 또는 수동 기록 라벨과 사진을 확인합니다.

통과 기준: 거짓 GPS 확인으로 표시되지 않고 선택한 확인 방식, 메모와 사진이 정확히 저장됩니다.

## 미션 3: 감상·프로필·업적

1. 방문한 장소에 별점과 감상을 저장합니다.
2. 프로필에서 방문, 사진, 리뷰, XP와 레벨 진행률을 확인합니다.
3. 월간 회고와 업적 상태를 확인합니다.
4. 저널에서 시간순 기록과 기념일 표시를 확인합니다.

통과 기준: 입력한 기록과 통계가 일관되게 반영되고 중복 XP가 생기지 않습니다.

## 미션 4: 강제 종료 영속성

1. 앱을 최근 앱 화면에서 완전히 종료합니다.
2. 앱을 다시 실행합니다.
3. 저장 장소, 태그, 방문, 사진, 리뷰와 XP를 확인합니다.
4. 가능하면 기기 재부팅 후 한 번 더 확인합니다.

통과 기준: 종료 또는 재부팅 후에도 모든 로컬 기록이 유지됩니다.

## 미션 5: 전체 백업과 복원

1. 프로필에서 JSON 백업을 내보냅니다.
2. Documents에 파일이 생성되거나 공유 시트가 열리는지 확인합니다.
3. 백업 파일을 안전한 위치에 보관합니다.
4. 테스트에 동의한 경우 앱 데이터를 초기화합니다.
5. 시스템 파일 선택기에서 같은 JSON을 선택해 복원합니다.
6. 저장 장소, 태그, 방문, 사진, 리뷰, XP가 모두 돌아왔는지 확인합니다.

통과 기준: 무결성 미리보기가 실제 건수와 일치하고, 유효한 백업만 전체 복원되며 실패 시 기존 데이터가 손상되지 않습니다.

주의: 내보낸 JSON은 좌표와 사진을 포함할 수 있고 별도로 암호화되지 않습니다. 공개 채널에 올리지 말고 테스트 뒤 삭제합니다.

## 미션 6: 선택적 로컬 AI 전송 경계

사전 조건: 제공된 더미 사진과 더미 메모, 직접 통제하는 OpenAI 호환 테스트 실행기, 실행기의 수신 요청 로그를 사용합니다. 개인 사진·실명·개인 메모를 사용하지 않습니다.

1. 로컬 AI 설정이 없거나 꺼진 상태에서 수동 기록 기능은 정상이고 AI 작성 버튼이 노출되지 않는지 확인합니다.
2. `localhost`/loopback 테스트 실행기를 저장하고, 연결 테스트가 기록 내용을 보내지 않는지 수신 로그로 확인합니다.
3. `http://192.168.x.x` 같은 HTTP 사설망 주소를 입력해 거부·차단되는지 확인합니다.
4. 유효한 인증서를 가진 `https://192.168.x.x` HTTPS 사설망 주소를 입력합니다. 정확한 엔드포인트 소유 확인 전에는 활성화되지 않고, 확인 문구가 기기 밖 전송·운영자 처리·TLS 암호화를 알리는지 확인합니다.
5. 공개 IP 또는 공개 호스트 이름을 입력해 공개·클라우드 엔드포인트가 차단되는지 확인합니다.
6. 더미 메모와 더미 사진을 선택해 전송 미리보기를 엽니다. 보내기 전 수신 로그가 비어 있고, 미리보기에 선택한 장소 이름·메모와 사진 포함 여부가 표시되는지 확인합니다.
7. 명시적 전송 버튼을 누른 뒤 수신 로그를 검사합니다. 요청에는 선택한 장소 이름·메모와 EXIF를 제거한 축소 임시 사진만 있어야 하며, 정확한 위치, 사진 메타데이터, 다른 기록, 백업과 API 키가 없어야 합니다.
8. 결과가 편집 가능한 초안인지 확인합니다. 초안 적용만 하고 기록 화면을 닫았다 다시 열어 자동 저장·동기화·공유되지 않았는지 확인한 뒤, 일반 저장을 실행했을 때만 기록되는지 확인합니다.
9. 실행기를 중지하거나 응답을 지연시켜 실패·타임아웃을 만듭니다. 실패 후에도 현재 입력과 기존 기록이 유지되고 재시도할 수 있는지 확인합니다. 테스트 후 실행기 수신 로그와 더미 파일을 삭제합니다.

통과 기준: 선택 전송 외 데이터가 수신 로그에 없고 HTTP 사설망과 공개 엔드포인트가 차단되며, HTTPS 사설망은 정확한 소유 확인 뒤에만 허용됩니다. 미리보기와 명시적 전송 확인 없이 요청이 발생하지 않고, 실패 시 입력·기록이 유지되며 AI 초안은 일반 저장 전까지 영구 저장되지 않습니다.

## 심각도

- P0: 앱 실행 불가, 데이터 전체 손실, 반복 충돌, 복원으로 기존 데이터 손상
- P1: 핵심 미션 완료 불가, 기록이 재시작 후 사라짐, 권한 없이 민감 기능 실행
- P1: 미리보기·명시적 확인 전 AI 요청, HTTP 사설망·공개 엔드포인트 허용, 위치·EXIF·다른 기록 유출, AI 초안 자동 저장
- P2: 일부 버튼·레이아웃·문구·성능 문제, 우회 가능
- P3: 개선 제안 또는 사소한 불편
