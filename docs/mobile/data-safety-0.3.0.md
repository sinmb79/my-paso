# Hello! My Paso! 0.3.0 — Google Play Data Safety 작업표

기준일: 2026-08-11
대상: `com.mypaso.app` 0.3.0 비공개 테스트 후보

이 문서는 법률 자문이나 정책 적합성 보증이 아니라, 현재 빌드의 실제 동작을 Play Console에 빠짐없이 옮기기 위한 작업표입니다. 실제 제출 화면, 엔드포인트의 소유·운영 관계와 최신 Google Play 정책을 다시 확인한 결과가 최종 답변입니다.

## 1. 공식 정의와 책임

- Google Play Data safety에서 `수집(collect)`은 앱이 사용자 기기 밖으로 데이터를 전송하는 것을 포함합니다. 따라서 같은 기기의 `localhost` 처리만으로는 수집이 아니지만, 사설망의 다른 기기로 보내는 AI 요청은 기기 밖 전송이며 수집으로 기록합니다.
- `선택 사항(optional)`은 사용자가 앱을 사용하면서 해당 수집을 켜거나 끌 수 있다는 뜻입니다. Paso는 AI를 설정하지 않아도 수동 기록 기능을 모두 사용할 수 있으므로 AI 전송 데이터는 선택 사항입니다.
- 2026년 7월 반영 사용자 데이터 정책은 제3자 AI 통합에도 제한된 사용, 공개와 동의에 대한 개발자 책임이 적용됨을 명시합니다. 앱의 미리보기와 명시적 전송 동작이 있어도 실제 운영 흐름과 정책 준수 책임이 사라지는 것은 아닙니다.

공식 근거:

- [Google Play Data safety 양식 안내](https://support.google.com/googleplay/android-developer/answer/10787469)
- [Google Play 사용자 데이터 정책](https://support.google.com/googleplay/android-developer/answer/10144311)
- [Google Play 명확한 공개와 동의 권장사항](https://support.google.com/googleplay/android-developer/answer/11150561)

## 2. 제품의 실제 전송 경계

- AI는 선택 사항이고 모델 가중치는 앱에 포함되지 않습니다. 소유자가 OpenAI 호환 한국어 모델 실행기를 별도로 준비합니다.
- 앱은 이 기기의 HTTP/HTTPS `localhost`·loopback 또는 사용자가 정확한 주소를 다시 확인한 HTTPS 사설망 IPv4 엔드포인트만 허용합니다.
- HTTP 사설망, 공개 인터넷, 클라우드 및 개발자 운영 AI 엔드포인트는 차단하고 HTTPS 사설망만 확인 뒤 허용합니다. API 키나 인증 정보를 저장하거나 전송하지 않습니다.
- 요청 전 전송 미리보기를 표시하고, 사용자가 **이 내용으로 AI 초안 만들기**를 눌러 명시적으로 확인해야 전송합니다.
- 요청 내용은 선택한 장소 이름·메모입니다. 비전 모델인 경우 새 캔버스에서 EXIF와 사진 메타데이터를 제거하고 축소한 임시 JPEG 복사본만 추가합니다.
- 정확한 위치, 방문 좌표, EXIF·사진 메타데이터, 다른 기록, 백업 데이터는 AI 요청에 포함하지 않습니다.
- HTTPS 사설망 전송은 기기 밖 전송이며 엔드포인트 운영자가 요청을 처리할 수 있고 플랫폼 TLS로 암호화됩니다. HTTP localhost는 기기 안에서 처리되므로 기기 밖 수집이 아닙니다. 22B Labs는 AI 엔드포인트를 운영하지 않고 요청을 수신, 보관 또는 열람하지 않습니다.
- AI 결과는 편집 가능한 초안입니다. 자동 저장·동기화·공유하지 않으며, 사용자가 적용한 뒤 일반 저장 동작을 완료해야 기록됩니다.

## 3. Console 작업 답변

| 데이터 유형 | 수집 | 공유 | 필수/선택 | 목적 | 근거 |
|---|---|---|---|---|---|
| `Photos` | **Yes — 사설망 AI 모드** | 아래 공유 판단 참조 | 선택 사항 | 앱 기능 | 비전 모델을 선택하고 사용자가 명시적으로 보낼 때 EXIF 제거 임시 사진 복사본 전송 |
| `Other user-generated content` | **Yes — 사설망 AI 모드** | 아래 공유 판단 참조 | 선택 사항 | 앱 기능 | 사용자가 미리보기에서 확인한 장소 이름과 메모로 기록·분류·키워드 초안 생성 |

추가 질문 작업값:

- 데이터가 일시적으로만 처리되는가: 앱은 임시 사진 복사본이나 AI 요청을 별도 저장하지 않습니다. 그러나 소유자 실행기의 메모리·로그·보관 동작은 앱이 통제하지 않으므로 Console의 문구와 실제 테스트 실행기 설정을 보고 보수적으로 다시 판단합니다.
- 전송 중 암호화: **Yes**. 기기 밖 수집은 사용자 확인을 거친 HTTPS 사설망 연결로만 가능하며 플랫폼 TLS를 사용합니다. HTTP는 localhost·loopback에만 허용되고 같은 기기 안에서 처리되므로 off-device collection이 아닙니다.
- 삭제 요청 방법: 계정이 없습니다. 로컬 앱 데이터는 앱 데이터 삭제 또는 앱 제거로 삭제합니다. 사용자가 운영하는 엔드포인트의 로그나 보관 데이터는 해당 운영자가 직접 삭제해야 합니다.
- 정확한 위치: AI 요청에서 수집하지 않습니다. 현장 방문 확인 시에만 기기 안에서 접근하고 백그라운드 위치를 사용하지 않습니다.
- 사진 메타데이터/EXIF: 수집하지 않습니다. 디코딩 후 새 JPEG로 다시 그린 임시 복사본만 전송합니다.
- 광고, 분석, 개인화, 사기 방지, 개발자 통신: AI 수집 목적에 해당하지 않습니다.

검증 주의: `전송 중 암호화: Yes` 답변은 HTTP 사설망이 실제로 차단되고 HTTPS 사설망 요청이 플랫폼 TLS 인증서 검증을 통과한다는 릴리스 빌드 증거가 있을 때만 확정합니다. 이 경계가 달라지면 Console 답변과 문서를 즉시 다시 검토합니다.

## 4. 공유 여부 판단 — 제출 직전 재확인

현재 제품 전제는 사용자가 자신이 관리하는 사설망 엔드포인트로 명시적으로 보내는 소유자 관리 흐름입니다. 이 전제와 Google의 사용자 주도 전송 예외를 적용하면 `공유: No`가 작업 후보입니다. 다만 아래 중 하나라도 사실이면 `Yes`로 수정하고 수신자와 목적을 정확히 신고합니다.

- 엔드포인트를 사용자와 다른 개인·법인이 운영합니다.
- 개발자 또는 개발자 서비스 제공자가 엔드포인트, 로그, 프록시나 모델 서버를 운영합니다.
- 전송 데이터가 모델 제공자 또는 다른 제3자에게 재전송됩니다.
- 사용자가 직접 선택한 전송으로 볼 수 없는 자동·백그라운드 전송이 생깁니다.

Console 제출 직전 확인 증거:

- [ ] 실제 테스트 엔드포인트의 소유자와 운영자를 기록했습니다.
- [ ] 프록시, DNS, 원격 분석 SDK와 클라우드 릴레이가 없음을 네트워크 로그로 확인했습니다.
- [ ] 전송이 미리보기 뒤 별도 사용자 동작으로만 발생함을 확인했습니다.
- [ ] 운영 관계를 기준으로 `공유: No/Yes`를 다시 선택하고 그 이유를 비밀 없는 증거 보고서에 기록했습니다.

## 5. 수신 로그 검증 체크리스트

개인 자료를 사용하지 말고 제공된 더미 사진·더미 메모로만 수행합니다.

- [ ] AI 비활성 상태와 전송 미리보기 단계에서는 수신 로그가 비어 있습니다.
- [ ] HTTP/HTTPS loopback과 정확히 확인한 HTTPS RFC1918 사설망 주소만 연결됩니다.
- [ ] HTTP RFC1918 사설망 주소는 거부되고, HTTPS 사설망은 정확한 소유 확인 뒤 허용됩니다.
- [ ] 공개 IP, 호스트 이름, 자격 증명 포함 주소, 경로·쿼리·프래그먼트 포함 주소가 차단됩니다.
- [ ] 명시적 전송 뒤 선택한 장소 이름·메모만 텍스트 입력에 있습니다.
- [ ] 비전 요청 사진은 축소 JPEG이고 EXIF, 위치와 원본 메타데이터가 없습니다.
- [ ] 정확한 위치, 방문 좌표, 사진 ID, 다른 기록, 백업과 API 키가 없습니다.
- [ ] 오류·취소·타임아웃 뒤 현재 입력과 기존 기록이 유지됩니다.
- [ ] 초안 적용만으로 영구 저장·동기화·공유되지 않습니다.
- [ ] 테스트가 끝난 뒤 실행기 수신 로그와 더미 파일을 삭제했습니다.

## 6. Play Console 업데이트 체크리스트

- [ ] 개인정보처리방침의 0.3.0 국·영문과 앱 내 전송 미리보기 문구가 일치합니다.
- [ ] `Photos`와 `Other user-generated content`를 선택적 수집, 앱 기능 목적으로 입력합니다.
- [ ] 사설망 모드의 수집 질문에 `Yes`로 답합니다.
- [ ] 실제 소유·운영 흐름을 확인해 공유 답변을 확정합니다.
- [ ] HTTP 사설망 차단과 HTTPS 사설망의 플랫폼 TLS를 검증한 뒤 전송 중 암호화를 `Yes`로 답합니다.
- [ ] 정확한 위치와 EXIF/사진 메타데이터를 AI 수집 항목으로 추가하지 않습니다.
- [ ] 스토어 설명, 릴리스 노트와 테스터 안내가 동일한 선택·미리보기·초안 경계를 설명합니다.
- [ ] 제3자 AI의 제한된 사용, 공개와 동의 책임을 검토하고 공개·클라우드 경로가 차단됨을 다시 확인합니다.
- [ ] Console 저장 후 검토 화면을 캡처하되 계정, 쿠키, 비밀 값과 개인 테스터 정보는 가립니다.
