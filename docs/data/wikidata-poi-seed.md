# Wikidata 대한민국 POI 시드

기준 스냅샷: 2026-07-19
시드 버전: `wikidata-ko-2026-07-19-v1`
레코드 수: 100
POI JSON SHA-256: `41bf792ce9b610b66900c9439aec332b4422443cf008200029ce669c88485d7e`

## 목적과 원칙

공개 출시 후보에서 생성형 더미 좌표를 실제 장소로 오인하게 해서는 안 됩니다. 동시에 런타임 API 키나 네트워크 장애가 앱의 핵심 기록 흐름을 막아서도 안 됩니다. 따라서 Wikidata에서 대한민국 장소를 한 번 수집·검증한 뒤 고정 스냅샷으로 번들하고, 앱 실행 중에는 외부 POI API를 호출하지 않습니다.

Wikidata의 main/property/lexeme namespace 구조화 데이터는 CC0로 제공됩니다. 이번 시드는 이름, QID, P31 유형, P625 좌표, P17 국가, P131 행정구역과 선정용 sitelink 수만 사용합니다. Wikipedia 본문과 Wikimedia Commons 이미지는 포함하지 않습니다.

- [Wikidata 공식 라이선스 정책](https://www.wikidata.org/wiki/Wikidata:Licensing)
- [Wikidata 공식 데이터 접근 안내](https://www.wikidata.org/wiki/Help:Data_access)
- [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

## 파일과 재현 증거

- 앱 시드: `src/lib/poi/pois.json`
- 출처·쿼리·레코드별 QID: `src/lib/poi/seed-manifest.json`
- 생성기: `scripts/seed-pois.mjs`
- 제3자 고지: `THIRD_PARTY_NOTICES.md`

재생성 명령:

    npm run seed:wikidata

Wikidata는 계속 갱신되므로 미래에 같은 쿼리를 실행한 결과가 완전히 같다고 보장할 수 없습니다. 출시 증거의 기준은 저장소에 고정한 JSON, 매니페스트와 SHA-256입니다.

## 기존 알파 데이터 마이그레이션

앱은 시작할 때 실제 시드를 QID 기반 ID로 upsert합니다. 기존 `source=dummy` 행은 삭제하지 않고 일반 지도·탐색에서 제외합니다. 과거 테스트 장소를 참조하는 방문·리뷰·저장·태그 행과 JSON 백업의 참조 무결성은 유지되지만, 레거시 저장·태그는 일반 탐색 UI에 다시 노출하지 않습니다. 원시 전체 백업은 레거시 POI도 포함하며, 새 설치와 일반 탐색 목록에는 실제 100건만 표시됩니다.

## 정확도 한계와 운영 규칙

Wikidata `P625`는 장소 중심점일 수 있으며 반드시 출입구나 체크인 지점은 아닙니다. 음식점의 영업 상태와 시설 운영 시간도 스냅샷 이후 달라질 수 있습니다. 앱은 GPS 확인과 수동 기록을 구분하고 수동 기록을 항상 허용합니다.

프로덕션 전과 정기 갱신 때에는 다음을 별도 검수합니다.

1. 운영·폐업 여부가 중요한 POI의 공식 사이트 대조
2. GPS 오차가 큰 장소의 출입구 또는 대표 지점 검토
3. 변경·삭제 QID와 중복 장소 확인
4. 새 스냅샷의 테스트·해시·매니페스트 재생성
