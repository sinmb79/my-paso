1. 운영자 및 문의처

서비스 운영자: 22B Labs
문의: sinmb82@gmail.com

2. 개발자가 수집하거나 공유하는 데이터

없습니다. Hello! My Paso!는 계정 가입을 요구하지 않으며, 사용자의 개인정보나 앱 사용 데이터를 개발자 서버로 전송하지 않습니다. 광고, 행동 추적, 원격 분석 도구도 포함하지 않습니다.

3. 기기에 저장되는 데이터

사용자가 앱에서 만든 프로필, 저장한 장소와 태그, 방문 기록, 수동/GPS 확인 상태, 방문 좌표, 리뷰, 사진, XP 및 설정은 앱 전용 로컬 저장소에 보관됩니다. 사진 파일은 앱 전용 미디어 영역에, 나머지 기록은 로컬 데이터베이스에 저장됩니다. 개발자는 이 데이터에 접근할 수 없습니다.

4. 권한과 네트워크

  • 위치: 사용자가 “현재 위치 확인”을 누른 경우에만 선택한 장소의 현장 방문 여부를 확인합니다. 백그라운드 위치를 수집하거나 추적하지 않습니다.
  • 카메라·사진: 사용자가 방문 사진을 추가할 때 촬영하거나 선택한 이미지에만 접근합니다.
  • 파일: 사용자가 요청한 JSON 백업을 문서 영역에 저장하고 공유 시트를 열기 위해 사용합니다.

100개의 번들 POI를 사용하므로 외부 공공 API 키 없이도 핵심 기능이 동작합니다. 인터넷 권한은 앱 콘텐츠 로드와 선택적 지도 기능에 사용되며, 개인 기록을 개발자 서버로 업로드하지 않습니다.

5. 보관, 백업 및 삭제

앱 데이터는 사용자가 앱 데이터를 지우거나 앱을 삭제할 때까지 기기에 남습니다. Android 클라우드 백업과 기기 간 자동 전송은 앱 설정에서 제외했습니다. JSON 백업에는 위치, 방문 기록, 태그와 사진 데이터가 포함될 수 있고 사용자가 선택한 위치에 별도로 저장되므로 사용자가 직접 관리하고 삭제해야 합니다.

6. 보안

데이터는 운영체제가 보호하는 앱 전용 영역에 저장됩니다. 백업은 체크섬과 참조 무결성을 검사하고 복원 실패 시 기존 로컬 기록을 유지합니다. 내보낸 JSON 파일은 별도로 암호화되지 않으며 위치와 사진을 포함할 수 있으므로 기기 잠금, 안전한 보관 및 신중한 공유를 권장합니다.

7. 아동의 개인정보

앱은 누구의 개인정보도 개발자 서버로 수집하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다. 이번 Play 비공개 테스트의 대상 연령은 만 18세 이상입니다.

8. 변경 사항

권한, 외부 전송, 계정, 분석 또는 동기화 방식이 달라지면 새 빌드를 배포하기 전에 데이터 안전성 신고와 본 방침을 실제 동작에 맞게 갱신합니다.

Privacy Policy (English)

Operator: 22B Labs · sinmb82@gmail.com

Hello! My Paso! closed-test version 0.2.0 requires no account and does not collect or share personal or app-usage data with developer servers. It contains no ads, tracking, or remote analytics.

Profiles, saved places and tags, visits, manual/GPS verification state, visit coordinates, reviews, photos, XP, and settings remain in app-private on-device storage. Location is accessed only when the user explicitly checks an on-site visit; background location is not collected. Camera or photo access occurs only when the user adds a visit photo. File access is used to write a user-requested backup and open the native share sheet.

Local data remains until the user clears app data or uninstalls the app. Android cloud backup and automatic device transfer are disabled. Exported JSON backups can include location and photo data, are not separately encrypted, and must be protected or deleted by the user.

The bundled 100 POIs let core features work without public API keys. Internet access does not upload personal journal records to developer servers. Material changes to permissions, external transfers, accounts, analytics, or sync will be reflected in this policy and the store Data safety declaration before release.
