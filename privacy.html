2. 개발자가 수집하거나 공유하는 데이터

없습니다. Hello! My Paso!는 계정 가입을 요구하지 않으며, 사용자의 개인정보나 앱 사용 데이터를 개발자 서버로 전송하지 않습니다. 광고, 행동 추적, 원격 분석 도구도 포함하지 않습니다.

3. 기기에 저장되는 데이터

사용자가 앱에서 만든 프로필, 방문 기록, 리뷰, XP 및 설정은 앱 전용 로컬 저장소에 보관됩니다. 이 데이터는 사용자의 기능 이용을 위해서만 처리되며 개발자가 접근할 수 없습니다.

4. 권한과 네트워크

버전 0.1.0은 위치, 카메라, 사진, 파일 저장소와 같은 민감한 런타임 권한을 요청하지 않습니다. 외부 지도 및 공공 API 키 없이 100개의 번들 POI 데이터를 사용하므로 핵심 기능은 오프라인에서 동작합니다. 사용자가 이메일 링크 등 외부 앱을 직접 여는 경우에는 해당 외부 서비스의 정책이 적용됩니다.

5. 보관, 백업 및 삭제

앱 데이터는 사용자가 앱 데이터를 지우거나 앱을 삭제할 때까지 기기에 남습니다. Android 클라우드 백업과 기기 간 자동 전송은 앱 설정에서 제외했습니다. 앱의 JSON 내보내기로 만든 파일은 사용자가 선택한 위치에 별도로 저장되므로 사용자가 직접 관리하고 삭제해야 합니다.

6. 보안

데이터는 운영체제가 보호하는 앱 전용 영역에 저장됩니다. 기기 잠금과 운영체제 업데이트를 권장합니다. 내보낸 JSON 파일은 앱 전용 영역 밖에 있을 수 있으므로 공유 및 보관에 주의해 주세요.

7. 아동의 개인정보

앱은 누구의 개인정보도 개발자 서버로 수집하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다. 이번 Play 비공개 테스트의 대상 연령은 만 18세 이상입니다.

8. 변경 사항

향후 위치, 카메라, 지도 또는 외부 API 기능을 활성화하면 출시 전에 권한, 데이터 안전성 신고 및 본 방침을 실제 동작에 맞게 갱신합니다.

Privacy Policy (English)

Operator: 22B Labs · sinmb82@gmail.com

Hello! My Paso! closed-test version 0.1.0 requires no account and does not collect or share personal or app-usage data with developer servers. It contains no ads, tracking, or remote analytics.

Profiles, visits, reviews, XP, and settings created in the app remain in app-private on-device storage. This version does not request sensitive runtime permissions such as location, camera, photos, or file storage. Its core features use 100 bundled POIs and work offline without external map or public API keys.

Local data remains until the user clears app data or uninstalls the app. Android cloud backup and automatic device transfer are disabled for this app. JSON files exported by the user are stored separately and must be managed or deleted by the user.

If future releases enable location, camera, maps, or external APIs, this policy and the Google Play Data safety declaration will be updated before release.
